# Model files

Place legacy unquantized FP32 `llama2.c` checkpoint files in this directory.
Checkpoint files (`*.bin`, `*.gguf`, and common model archive formats) are
ignored by Git and are not distributed with this repository.

The validated small checkpoint is available from:

https://huggingface.co/karpathy/tinyllamas/resolve/main/stories15M.bin

Its validation SHA256 is recorded in `benchmarks/llama/VALIDATION.md`.
